
# Contact Book Application

## Introduction
Contact Book is a Python Flask-based web application
used to manage personal contacts.

## Features
- Add new contacts
- View all contacts
- Search contacts
- Delete contacts
- Count total contacts

## Technologies Used
- Python
- Flask
- HTML
- CSS

## Installation

Install Flask:

pip install flask

## Run Application

python app.py

Open browser:

http://127.0.0.1:5000
